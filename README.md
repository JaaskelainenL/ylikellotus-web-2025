# Ylikellotus 2025

## Development

1. Install npm
2. Run `npm run watch` (runs TailwindCSS)
3. Run `npm run serve` in another terminal (runs http-server)
4. Open <http://localhost:8000>

## Publish

1. Publish to GitHub Pages using `npm run publish`

Any custom CSS should be made in "input.css", not "styles.css", which will be overwritten by TailwindCSS.
